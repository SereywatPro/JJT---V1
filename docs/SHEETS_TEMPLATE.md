# Google Sheets Template Reference

This document describes the exact column headers required in each sheet.  
The Apps Script (`gas/Code.gs`) will create these sheets and headers automatically on first use.

---

## Sheet 1: `Trades`

Row 1 must contain exactly these headers (in this order):

```
trade_id | date_open | date_close | symbol | market | direction | setup | timeframe | entry_price | stop_loss | take_profit | exit_price | position_size | fees | account_balance | risk_amount | pnl | r_multiple | result | emotion | followed_plan | mistake_tags | notes | screenshot_url
```

**Notes:**
- `trade_id` is auto-generated by the Apps Script (format: `TRD-{timestamp}-{random}`)
- `followed_plan` is stored as `Yes` or `No`
- `mistake_tags` is comma-separated, e.g. `Early exit, Moved SL`
- `date_open` and `date_close` are ISO datetime strings

---

## Sheet 2: `Daily_Review`

Row 1 must contain:

```
date | mood | trades_count | daily_pnl | went_well | to_improve | plan_tomorrow
```

**Notes:**
- `date` is in `YYYY-MM-DD` format
- `mood` is one of: `Great`, `Good`, `Neutral`, `Bad`, `Terrible`

---

## Sheet 3: `Settings`

Row 1 must contain:

```
key | value
```

**Default rows written on first save:**

| key | example value |
|---|---|
| starting_balance | 10000 |
| default_risk_pct | 1 |
| daily_loss_limit | 300 |
| max_trades_per_day | 5 |
| symbols | XAUUSD,EURUSD,BTCUSDT |
| setups | Breakout,Pullback,Reversal |
| mistake_tags | Early exit,Moved SL,Overtrade |

---

## Manual Setup (if not using Apps Script)

1. Open Google Sheets → create a new spreadsheet.
2. Rename Sheet1 to `Trades`.
3. Add Sheet2 named `Daily_Review`.
4. Add Sheet3 named `Settings`.
5. In each sheet, add the header row from above.
6. Share the sheet with the Apps Script service account (if using service account auth instead of OAuth).

> The easiest approach is to deploy `gas/Code.gs` as a Web App — it handles all sheet creation automatically.
